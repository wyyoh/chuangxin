## Risk

Remaining release risks:

- A final release branch must still verify the exact no-pthread ABC binary that
  will be packaged.
- A packaged `submit/` directory and `submit_sharecone.zip` still require
  separate explicit user approval.
- The large public output evidence should not be confused with the formal
  submitted archive.

The formal config-name risk is now resolved in this preflight branch: the
candidate reproduces when installed as `configs/final_selector.yaml` and
`configs/pipelines.yaml`.

## Selector Eligibility

The selector still uses coarse structural features only. The `r7b_eligible`
feature is generated by `r7win -profile -diag`, and the R8 online choose-best
policy accepts deterministic declaration-order variants only after CEC and
level checks. It does not use file names, directory names, hashes, public case
IDs, exact public fingerprints, or exact port names.
